# cubchoo_ogerpon_rb

クマシュン / オーガポン いしずえのめんex デッキ専用のルールベースエージェントです。

提出時は、このディレクトリを `--agent` に指定します。

```powershell
uv run python scripts\build_submission.py --agent agents\cubchoo_ogerpon_rb --deck decks\candidates\2026-06-30_top5\winrate_1_cubchoo_ogerpon.csv
```

Kaggle提出zipの中では、この `main.py` がルートの `main.py` として使われます。
