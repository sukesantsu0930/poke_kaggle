## 実装の要点

- **色対応エネ勘定 `_payable()`**: ロケット団エネルギー(15)は {P}{D} 2個ぶん。基盤の
  枚数ベース `payable_attacks` では ミュウツー（ロケットエネ1+任意1で起動）を判定できない
  ため、plan_attacks / S-0 / 前出しランクを全て `_payable()` に差し替えている。
- **guard_damage をアタッカー毎の弱点計算に差し替え**（ATTACK_ENERGY_TYPE 1本だと
  ミュウツーの超打点まで草弱点2倍になるため）。
- ロケットラッシュ = 場のロケット団×30 / ダークフロスト = 60+ロケットエネで+60 /
  イレイザーボール = 160 固定（任意トラッシュは v1 不使用）。
- ベンチは絞らない（盤面数=打点。R-24 不適用）。チャージアップ(28500)・ファクトリー2ドロー
  (28000) が最上位帯。
