# 候補デッキ

外部メタ分析から exact 60枚で抜き出した候補デッキです。

既存5候補は 2026-06-30 の1000 episode分析から作成したものです。`popular_4_dragapult.csv` はドラパルト系の代表episodeを追加取得して作成した候補です。

公開episodeの勝率は、デッキ性能と操作者/Agent性能が混ざっています。採用前に手動GUIと対応Agentで確認してください。
