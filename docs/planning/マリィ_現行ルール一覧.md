# マリィ（オーロンゲex + マシマシラ）現行ルール一覧

`agents/marnie_munkidori_rb/main.py` が **2026-07-27 時点で実際に動かしているルールの全量**。
設計意図・実験経緯は [デッキ設計_マリィ.md](デッキ設計_マリィ.md)、基盤の R-xx は
`agents/_base/policy_base.py`。**このファイルは「今どう動いているか」だけを書く**。

読み方: 決定は「候補手それぞれにスコアを付けて最大値を選ぶ」方式。**スコアが大きいほど先に実行**
されるので、下の数値表がそのまま**ターン内の行動順序**になる。負のスコア = その手は選ばない（マスク）。

## 0. 骨格（ユーザー認識との対応）

| ユーザーの言う骨格 | 実装での担当 |
|---|---|
| 進化して殴る | S-3（アメ→オーロンゲ 25000）+ S-0 サブゴール判定（場のオーロンゲにエネ2枚） |
| マシマシラにエネを張る | S-5 手張り（マシマシラ 8300 = **オーロンゲより上**。ただし1体につき1枚）。**手張りの相手はマシマシラとオーロンゲだけ** — ライン駒への手張りは禁止で Punk Up に任せる |
| 3点返しをどこに飛ばすか | E-2 Adrena-Brain（移動元 → 数量 → 配置先の**3段階**。MAR_DMGMOVE） |

実装はこの3本に加えて **①場を作る手（グッズ/サーチ）が最上位帯 ②サーチ先の優先梯子
③ボスの吊り出し ④ベンチ30 の照準** を持つ。以下が全量。

## 3. Punk Up（オーロンゲ進化時に山から悪エネ5枚まで）

エンジンは「①山から何枚取るか（ATTACH_TO）→ ②どのポケモンに付けるか（ATTACH_FROM）」の順で聞く。

**① 取得枚数**（div-3 + div-8）
```
必要枚数 = Σ(オーロンゲの 2−現エネ) + (悪エネ0のマシマシラ 1体につき 1)
先置き分 = min(2, Σ(ベロバー/ギモーの 2−現エネ))
        ただし「これ以上オーロンゲが場に出せない」なら 0（MAR_ATT4）
取得 = clamp(必要 + 先置き, 1, 5)   ← 残りは山に温存（次の Punk Up の弾）
```

**② 付け先**（MAR_ATT4。同種内は傷の浅い個体を優先）

| スコア | 付け先 | 条件 |
|---:|---|---|
| 15000 | オーロンゲ | エネ2枚未満（＝この番殴るための燃料。脅威でも付ける） |
| 8000 / 7000 | ベロバー / ギモー | エネ2枚未満 ∧ **進化路が残っている** ∧ 脅威に晒されていない。エネ1枚の駒は +300（集中投資） |
| 3000 | オーロンゲ（満タン） | div-7: 2枚目以降は付けず次のライン駒へ回す |
| 900 | 脅威に晒されたライン駒 | 倒される駒に付けた悪エネはトラッシュ直行 |
| 500 | 進化路が尽きたライン駒 | **場に出せるオーロンゲ = 3 − 場 − トラッシュ** を超える先置きはしない |

※ マシマシラは Punk Up の対象外（「マリィのポケモン」ではない）= **悪エネは手張りでしか入らない**。

## 4. Adrena-Brain（自分のダメカン3個までを相手1体へ）— 3段階

**⓪ 配分ドクトリン【ユーザー決定 2026-07-27・MAR_DMGPLAN】** — マシマシラの3点と
Shadow Bullet のベンチ30 に**共通**で適用する優先順位。

> 効率よくサイドを取ることを考えたとき、**試合終了時に相手盤面にダメカンが残っていたら
> 非効率だった**ことを意味する。**相手が進化するかどうかでこちらのプランが崩れる**のも弱い。

| 順位 | 条件 | 例 |
|---|---|---|
| ① | **相手バトル場**の確定数がずれる | 残210 に 30 載せて **180 = Shadow Bullet 1発圏** |
| ② | **相手ベンチのアタッカー**（エネ付き/ex/2進化）で確定数がずれる | |
| ③ | 相手ベンチで**進化先が存在せず**最も残HPが低い駒 | 進化する **70** ではなく進化しない **110** に載せ続ける |
| ④ | 進化で崩れる駒・確定数をずらせない駒 | 最後 |

- **確定数** = ceil(残HP ÷ 主力打点)。主力打点は Shadow Bullet 180 を基準にする
  （オーロンゲ不在時に前座の10点技で数えると「29発が28発」の無意味な判定が混ざるため）。
- 同順位内は「**倒すのが近い（確定数が小さい）> 要る枚数が少ない > ex > 残HPが低い**」。
  370HP に1個（3発→2発）より **210HP に3個（2発→1発）** を優先する。
- 動かす枚数は **①②なら「ずらすのに要る最小枚数」だけ**（過剰打点＝盤面に残るダメカンの防止）、
  ③④なら最大枚数（自陣の回復を最大化しつつ蓄積）。
- 進化の有無は `CardData.evolvesFrom`（進化元の名前）を全カード分集めて逆引きで判定する。

**① 移動元**（div-11 v2 + MAR_DMGMOVE(c)）

| スコア | 移動元 |
|---:|---|
| 3000+dmg | ダメージ60以上のマシマシラ（重傷の救出） |
| 2000 | バトル場の駒 |
| 1000+dmg | 最も傷ついたベンチ |
| +600 / +300 | KO プランを賄えるだけダメカンを持つ駒 / R-08 脅威に晒された駒（加点） |

**② 数量**（MAR_DMGMOVE(a)）
- 「今ターン or 次ターンに **KO 圏へ入れる最小移動数**」を計画して、その枚数だけ動かす
- 計画が立たない時は**最大数**（＝自陣の回復を最大化）

**③ 配置先**（MAR_DMGPLAN）

| スコア | 配置先 |
|---:|---|
| 18000 | ②で立てた計画の対象（数量と配置の整合） |
| 17000 − rank×3000 − 確定数×100 − … | ⓪の順位表（rank0=相手バトル場 … rank4=進化で崩れる駒） |

**E-2a【ハード・ユーザー決定】**: 自分のバトル場の**攻撃だけで相手バトル場を倒せる**なら、
ダメカンは相手バトル場に置かず**ベンチへ回す**（過剰打点の防止）。
※ 上位勢の観戦では反証が出ている（攻撃で倒せる相手にも載せる 34x）が、ユーザー決定のため維持。

## 5. サーチ先の優先梯子（TO_HAND。ジム/ラムダ/パッド/ポフィン/ポケギア共通）

**大前提: 即プレイできる駒を持ってくる（MAR_PLAYABLE・ユーザー観戦 2026-07-27）**

> 場にベロバーしかいないのに、1進化のギモーをすっ飛ばしてオーロンゲを持ってきて、
> 番を返すという滑稽な振る舞いを確認しました。

- **この番のうちに場へ出せないポケモンは帯を 1/10 に圧縮**する（−1 マスクにしないのは、
  候補が全部即プレイ不可でも1枚は選べるようにするため）。
  判定は**場の駒だけ**で行う — 同じ番に出したたねは進化できないので、手札のベロバーを
  数えて「オーロンゲが出せる」と判定してはいけない。
  たね = ベンチに空き / 1進化 = 進化元が場 / 2進化 = ギモーが場、または ベロバーが場 ∧ 手札にアメ。
- **アメ直行が使えない局面ではギモーが唯一の進化路**なので +6500（ベロバー 6000 の上）へ。
  div-13 で「ギモーの取りすぎ」として下げた +800 は、その条件以外では維持する。
- 実測（均等7対面・140戦）: TO_HAND で取ったポケモンのうち「この番出せない駒」が
  **34.7% → 17.3%**、**オーロンゲの空取りが 156件 → 28件（−82%）**、
  ギモーの取得は 148 → 269件に増加。

`base = 250 − 手札の同名枚数×100` に以下を加算（MAR_SEARCH で決定化済み）。

**オーロンゲ +9000**（進化路がある時。無ければ 4200）> **アメ +8000**（場にベロバー）>
**ジム +7000**（自分のジムが出ていない）> **ベロバー +6000**（線<2）> **ポフィン +5500** >
**マシマシラ +5000**（2体未満）> ユキメノコ +3600 > 悪エネ +3500 > ユキワラシ +2900 >
ヒカリ +2600 > **ボス +2400（交戦期）** > スクラッパー +2200（相手にどうぐ）>
ラムダ +1600 > ポケギア +1500 > パッド +1200 > リーリエ +1000 > ギモー +800 >
スタンプ +700 > 夜タンカ +400 > その他 +250

**ポケギア3.0 だけは別梯子**（候補が全部サポートなら発生源はポケギアと同定できる）:
**序盤はドロー・終盤はボス** — リーリエ +8000（非交戦）/ ボス +9000（交戦期）/ ラムダ +2500 / ヒカリ +2000。

## 6. 前出し・吊り出し・ベンチ狙撃

**自分の前出し（TO_ACTIVE / SWITCH）**: 種の序列は オーロンゲ 15000+エネ×100 > モルペコ 9000（死文）>
ギモー 4500 > ベロバー 4000 > ユキワラシ 3800 > ユキメノコ 3100 > **マシマシラ 3000（div-1: エンジンは前に出さない）**。

**同種の個体差は MAR_PROMOTE【ユーザー決定 2026-07-27】**:

> Shadow Bullet が確定している/打つ可能性があるときは、もっとも打てる可能性のあるポケモンを
> バトル場に出す。打てないことが確定している場合は、いけにえから出す。この場合マシマシラではなく
> ベロバーラインが妥当 — 仮にオーロンゲに進化できた場合は、特性でバトル場にエネルギーをつけて
> 逃げて殴る、ということができるから。

- **打てる可能性がある**（場にオーロンゲがいる、または 場のギモー+手札のオーロンゲ /
  場のベロバー+手札のアメ+オーロンゲ で進化1手）→ **化ける個体を前に**（+600）、次にエネの乗った個体（+エネ×50）
- **打てないことが確定** → **いけにえ**。ベロバーライン優先（+250）で、同種内は
  **エネを載せていない個体から**差し出す（−エネ×150。載せた投資を捨てない）

**ボスの吊り先（MAR_PULL）**: 倒せる駒が複数いる時は **サイド枚数（ex=2）> 相手のアタッカーを潰す
> 残HPが低い**（旧実装は ex 加点だけで、残HPが同じだと同点＝インデックス順だった）。
非キル時は 縛り（エネ無し +200・低残HP 加点）。
※ 残HPは 2026-07-27 に二重引きバグを修正済み（MAR_BOSSHP）
