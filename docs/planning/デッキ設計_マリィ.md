## 交戦期（E-x）

- E-1 デフォルト攻撃 Shadow Bullet 180+30。ベンチ30 は R-15（相手の低HPエンジン駒）
- E-2 **Adrena-Brain を毎ターン使う**: 移動元=自分の最damage 個体（Grimmsnarl 優先=回復）、
  移動先= 30 で KO できる相手 > 低HP エンジン駒（R-15）。タンク+削りの両立がこのデッキの核
- **E-2a 移動先の振り分け（2026-07-06 ユーザー決定）**【ハード】: バトル場のポケモンの
  攻撃ダメージだけで相手のバトル場を倒せる場合、30点は相手バトル場に載せず**ベンチに回す**。
  対象は**HPが一番低いベンチポケモン**。（過剰打点の防止。Shadow Bullet のベンチ30と合わせて
  ベンチの駒を圏内に入れていく）
- E-3 クセロシキ: 相手手札が多い時。**対 Alakazam は Powerful Hand の打点を直接削る**ため優先度最大
- E-4 勇者のマント → Grimmsnarl（420 タンク、相手最大打点テーブルの全値を上回る）
- ノココッチ: 手札が細い時だけ Run Away Draw（使うと盤面から消える点に注意）
