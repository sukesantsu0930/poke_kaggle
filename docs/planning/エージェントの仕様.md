エージェントの仕様
ゲーム前半：コンセプトの実現（意思決定に相手無視）
ゲーム後半：詰めにいく（意思決定に相手考慮）

自身のデッキに紐づいたコンセプト（複数あってもここで1つ選択したもの）をまずは実現を目指す．意思決定に相手の情報はあまり関係ない．蓄積はするが．
そしてコンセプトを実現後，詰めにいく．

例）ドラパルトのファントムダイブがコンセプトのデッキ
前半：ドラパルトに進化し，エネルギーを揃えるのが目的（相手考慮なし）
後半：ファントムダイブで試合を詰める方向にシフト（ここから相手を考慮する）

環境遷移は API をオンラインでも使う．使い方は主に，次ターンで負けるか否かのチェックです．
嘘，大分話変わった．1 step における許された時間は 1s じゃ．これはもうモデル必須やなぁ．もっというと，モデルも考えなきゃいけない．相手が次のターンで勝つかどうかを一瞬で判定するモデルが必要．ホワイトボックスにできるかしら．いやぁ，かなりきついな．
