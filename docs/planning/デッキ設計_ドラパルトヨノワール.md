## 新カードの効果（カードDB実測 2026-07-14）

- **サマヨール 132** Cursed Blast: 相手1匹にダメカン5個(50)を置き自壊 / **ヨノワール 133**: 13個(130)を置き自壊。
  ベンチにも届く単体スナイプ。非exなので自壊＝**相手にサイド1を渡す使い切り**
- **マシマシラ 112** アドレナブレイン: 悪エネが付いていれば毎ターン、自分の1匹→相手の1匹へダメカン3個移動。
  自壊しない（エンジン上のタイプは超・弱点悪。Risky Ruins の「非悪」判定には自分も引っかかる点に注意）
- **ヒカリ 1231**（サポート）: 山からたね・1進化・2進化を各1枚サーチして手札へ
- **メイのはげまし 1240**（サポート）: **サイド残が相手より多い（負けている）ときのみ使用可**。
  トラッシュから基本エネ最大2枚を自分の**2進化**1匹へ付ける（対象はドラパルトex / ヨノワール）
- **Risky Ruins 1260**（スタジアム）: どちらの番でも、**非{D}のたねポケモンがベンチに出るたび**そのポケモンにダメカン2個。
  自分のたねも全員非{D}なので自傷リスクあり → 貼るタイミングの条件設計が必要

## ユーザー決定ルール（2026-07-14。強度ラベル付き）

1. **カーズドボムは「KOを取り切れる時だけ」爆発**【ハード】: ①130単体で落とせる ②Phantom Dive 正面200と合算で落とせる ③ばら撒き60と合算で押し切れる。それ以外は温存（サイド1を渡すリスク行動のため）。基本は2進化（ヨノワール）を目指す。
2. **悪エネの用途はマシマシラに貼る / にげるコスト充当のみ**【ソフト】。ボムと違い**再利用可能な資源**（アドレナブレインは自壊せず毎ターン使える）— 優先度設計はこの非対称を反映する。
3. **メイのはげましは限定運用**【ソフト・条件付き優先】: 通常はルール優先順位の下のほう（温存）。ただし**「使えないと技が打てない・使えばドラパルトが技を打てる」局面ではリーリエの決心より優先**。想定は試合後半のドラパルト緊急加速。
4. **アカマツはドラパルトライン優先、余裕があるときだけマシマシラへ**【ソフト】。
5. **Risky Ruins は攻撃の直前に張る**【ソフト（順序）】: 展開・圧縮・サポート・エネ付けを全部済ませ、ATTACK 宣言の直前に設置。自分のたねが設置後にベンチへ出る事故を同一ターン内で構造的に防ぐ。
6. **ヒカリはリーリエより下。ただし「この番ファントムダイブが打てる ∧ 手札にエネルギーがある」ときはヒカリ優先**【ソフト】（2026-07-14 ユーザー精緻化）: 攻撃が既に立っている番はリフレッシュで掘る必要が薄く、リーリエは手札を山へ戻すため、エネを保持したまま進化パーツを取りに行くヒカリが上回る。実装condは `can_main_attack`（Phantom Dive 支払い可能）AND 手札に基本エネ。どちらか欠けたらリーリエ > ヒカリ。
7. **偵察指令（ドロンチ特性）の順序原則 = 不確定ドローが先、確定サーチが後**【ソフト（順序）】（2026-07-14 精緻化）:
   欲しい札が複数あるとき、偵察指令（山上2枚から1枚＝不確定）を先に済ませ、**引けなかった方をポケパッド等の確定サーチで回収**できるため。
   - 標準順序: ポフィン等の盤面直行圧縮 →（このターン打つならリーリエ）→ **偵察指令 → ポケパッド**
   - リーリエを打つターンはリーリエ→偵察指令（先に取った札がリーリエで山へ戻る無駄の回避。R-26/R-28 と同じ構造）
   - ハイパーボールも確定サーチなので偵察指令の後、と解釈（ユーザー明言はポケパッドのみ。実装時に確認）
   - div-D3（旧型上位ピロット実測: ability→pokepad 103/38）とも同方向で整合
8. **サブゴール前のバトル場は捨て駒**【ソフト・R-29 一般ルール候補】（2026-07-14 ユーザー。
   起点=「ドラメシヤにエネを張って次の番に倒される」の観測）:
   ファントムダイブ実現までは、①スボミーを優先的にバトル場に出す（**逃げるためのエネ張りは容認**）
   ②ベンチになるべくドロンチを並べる ③攻撃するドラパルトはベンチで育てる。
   **次の相手番のリーサル判定でバトル場が飛ばされる見込みなら、バトル場に投資せずベンチを育てる**
   （ユーザー: 一般ルールでもいいくらい → R-29 候補としてルール抽出mdに登録、本デッキで先行実装）。
   - **8b（同日追記）: 進化先もベンチ優先** — ドロンチはベンチのドラメシヤへ。バトル場の
     ドラメシヤ（捨て駒）には進化を注がない。ベンチに対象が無ければ従来通り進化（優先であって禁止でない）。
9. **ミストエネルギー装着体をばら撒きで指定しない**【ハード】（2026-07-14 ユーザー）。
   **重要な機構訂正**: ミスト/ロックファイティングのテキストは「相手の**ワザの効果**を防ぐ
   （Damage is not an effect）」— つまり ①ばら撒き（ダイブの効果）は防がれる ②正面200（ダメージ）は
   通る ③**カーズドボム/アドレナブレイン（特性）は貫通する**。ガードを「ワザ効果用（ミスト含む）」と
   「特性用（本体特性のみ）」に分離実装。ロックファイティングの防御は {F} ポケモン装着時のみ。
   → 対イワパレスの「ボム+アドレナで取る」プラン（ユーザー案）は機構的に成立する（以前の
   「ボムはミストで消される」という当方の分析は誤りで訂正）。
10. **詰まり脱出コンボ**【ソフト】（2026-07-14 ユーザー）: 序盤に「エネルギーが張れない または
    進化できない」が成立する番は、ハイパーボールを切ってニャースex（Last-Ditch Catch）に繋ぎ、
    サポートサーチで**リーリエまで直行**する（詰まり時はボスよりリーリエ優先）。
11. **スタジアムは温存しない**【ソフト（順序）】（2026-07-14 ユーザー）: 基本張る。攻撃前に手札に
    残っていたら攻撃前帯（正帯最下層）で必ず張る。保持するのは自分のスタジアムが場に出ている間だけ。
    相手スタジアムの置換と T1 監視塔は即時（80000 帯）。
12. **ポフィン/ポケパッドは積極使用・温存しない**【ソフト】（2026-07-14 ユーザー）:
    ポケパッドの対象にボチ・マシマシラも追加（サーチ対象が山に残る限り常に正帯）。
13. **ばら撒きの即殺優先順位 = 投資済みから**【ソフト】（2026-07-14 ユーザー）: 取り切れる候補が
    複数あるときは、エネルギーが付いている・進化後のポケモンを優先して取る。実装 =
    `_plan_spread` の部分集合キーを（サイド, **投資度**, -消費個数）に拡張
    （投資度 = エネ枚数 + 進化済み+2）。単体テストで検証済み（同サイド同コストで投資側を選択）。

## アーキタイプ方針（2026-07-14 ユーザー宣言）

ゲームを **S-0 サブゴール（ファントムダイブ達成）** で2相に分け、それぞれ性格の違う決定方式を使う:

- **セットアップ期（サブゴールまで）**: **要求札を素直に数え、もっとも達成確率の高いプランで進める**。
  ファントムダイブ達成に足りない札（例: アメプラン = ドラメシヤ+アメ+ドラパルトex+エネ2色 / 進化プラン =
  ドロンチ経由）をプラン毎に列挙し、手札・山残・サーチ手段から達成確率を見て最尤プランに寄せる。
  サーチ（ヒカリ/ポケパッド/ハイパーボール/偵察指令）の取得対象・順序（ルール7）はこの要求札カウントに従属する。
  これを**ルールベースで実現する**のが目標（学習に頼らない）。
- **交戦期（サブゴール後）**: **planning** — 正面200 × ばら撒き60 × ボム130（×アドレナブレイン3個）の
  資源配分計画（dragapult_rb S-7 の拡張、未設計項目の3資源統合）。

## 実装 v1（2026-07-14。agents/dragapult_dusknoir_rb/）

dragapult_rb を土台に移植。消えたカード（ハンマー/Latias/ブロック/ヘルメット）のルールを除去し、
ルール1〜7を以下の形で実装した。

### ルール1: カーズドボム（`_plan_bomb` + ABILITY/B-1）

- MAIN 毎に `_plan_bomb` が計画を再計算: 相手全ポケモンを走査し
  **mode1**（残HP ≤ ボム打点=130/50）/ **mode2**（アクティブ、200 < 残HP ≤ 200+打点、can_main_attack 前提）/
  **mode3**（ベンチ、60 < 残HP ≤ 60+打点、同前提）のみ候補化。mode1 優先 → サイド多 → 無駄少で択一。
- **相手残りサイド ≤ 1 では絶対に撃たない**【ハード】（自壊のサイド1で相手が上がる）。
- サマヨール(50)は「基本は2進化を目指す」に従い mode1 かつサイド2以上のときだけ。
- **リーサル統合**: ボム単体 or ボム+配分プラン（対象が重複しない場合の合算）で取り切りなら
  ABILITY を LETHAL_BAND+1 に昇格（攻撃より先に解決。ボム解決後の残りは通常の R-07 が拾う）。
- 対象選択（DAMAGE_COUNTER, effect=132/133）は計画対象に固定（500000）。
- mode2/3 の「合算で取り切り」は分業: ボム解決後に plan/`_plan_spread` が現HPで再計算するため、
  正面200・ばら撒き60側の照準は既存機構がそのまま合う。

### その他のルールの実装形

- ルール2: `_attach_score` で悪エネ→マシマシラ以外は -1、マシマシラ→悪以外は -1、
  `LINE_MAX_COST[MUNKIDORI]=1`・ボムライン=0【ハード】。悪エネ→マシマシラ = 8300
  （ドラパルトの +25000 帯より下 = アカマツの「余裕があるとき」が自然に出る = ルール4）
- ルール3: `_rosa_enables`（アクティブのドラパルトexの不足色がトラッシュで埋まる）∧ サイド負け
  → hand_score 47000（リーリエ45000超え）。それ以外 200（温存）
- ルール5: PLAY(Risky Ruins) = 500。正帯最下層（ATTACK=154 と END=0 の直上）なので
  「全行動を済ませた後・攻撃の直前」が構造的に出る。攻撃できないターンは -1（温存）
- ルール6: hand_score(ヒカリ) = 43000、`can_main_attack ∧ energy_in_hand≥1` で 46000
- ルール7: スコア帯で表現 — ポフィン 46000 > リーリエ(選出時) 45800 > 偵察指令 45700 >
  attach ≤45450 > ポケパッド 45000 > ハイパーボール 44000。進化 47500+ はリーリエより先
  （手札の進化パーツを山へ戻さない）。旧型 div-D3 の特性 56000 はユーザー決定で置換
- アドレナブレイン: marnie div-14/div-11 v2 を移植（own_damage 時のみ・攻撃直前帯 2500、
  移動元はドラパルトライン回復優先・マシマシラ自身は重傷 60+ のみ救出）。移動先は
  取り切り(≤30) > 優先スナイプ(相手ヨノワール等) > R-15
- アカマツ S-6a を3色対応に一般化（残り色の最良付け先価値が最大になる色を手札に取る）
- R-11 の ACTIVATE 辞退はボム/アドレナを除外（ドロー特性ではないため）
- ルール8/R-29（2026-07-14 追加実装）: `_attach_score` にセットアップ期のバトル場ブロックを追加 —
  ①あと1枚で逃げコストが揃い、スボミー待機 or ベンチアタッカーありなら**逃げエネ 21000**（S-1b）
  ②それ以外で `opp_max_damage ≥ 残HP`（飛ばされる見込み）なら **-1**（R-29 マスク）。
  アタッカー（ドラパルトex/フェザン）は起動優先で例外。ベンチへの加速（+25000 帯）は不変 =
  「ドラパルトはベンチで育てる」が相対的に立つ。スボミー優先の前出し（promote +100000）と
