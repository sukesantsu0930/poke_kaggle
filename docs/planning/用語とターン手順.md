# 用語とターン手順

作成: 2026-07-06。「ルール」という語が広すぎるので、型を分けて呼び分ける。ここが用語の正典。

## 用語（案）

| 用語 | 定義 | 例 |
|---|---|---|
| **判定** | 盤面(obs)から真偽を返すだけの関数。行動を選ばない | リーサル判定、被リーサル判定、サブゴール判定 |
| **マスク** | 候補手の除外。ハード。違反手は選択肢から消える | エネ過剰付与禁止、山札切れガード、ロス手除外 |
| **優先則** | スコアによる順序付け。ソフト。他要因で覆り得る | 行動順序スコア帯、ターゲット評価 |
| **手順** | 判定→分岐の順序列。上位が発火したら下位は見ない（辞書式） | ターン手順（下記） |
| **サブゴール** | デッキコンセプト上の中間目標を判定の形で書いたもの | 「ブリジュラスが技をうてる」 |
| **フェーズ** | 有効なマスク・優先則・手順の組。サブゴール判定で遷移する | セットアップ期 / 交戦期 |

「ルール」は口語の総称として残す。文書・コードではこの5分類で書く。
`ルール抽出_オープン実装.md` の強度ラベルとの対応: 【ハード】=マスク、【ソフト】=優先則、【プロセス】=開発手順（エージェント外）。

## ターン手順（決定版・毎手番）

リーサル → 負け筋カット の順位付き実行は決定事項（2026-07-06）。

```
毎手番（MAIN 選択のたび）:
0. 安全マスク（常時）: R-01〜03, R-10, R-11, R-23
1. リーサル判定（常時・閉形式）:
     AttackPlan 最大打点 + ばら撒き + ボス込みで相手の残りサイドを取り切れるか?
     → YES: 勝ち切り手順へ（交戦期は探索検証つき: 勝ち筋を search API で確認して再生）
2. 被リーサル判定（常時・閉形式・ボス想定 = R-08）:
     → ロス手をマスク（辞書式緩和: 最悪ケース回避 → 可視のみ → least-bad）
3. フェーズ分岐:
     サブゴール未達 → セットアップ優先則（相手はほぼ無視、コンセプト実現に直進）
     サブゴール達成 → 交戦優先則（相手考慮の詰め）
```

## 「いつからターン手順を回すか」の整理

- **判定（手順の1と2）は常時回す。** 閉形式の算術だけなので実測 μs〜ms 級でコストが無い。リーサルの見逃しは純損（相手の事故・ドンク圏は序盤にも来る）。セットアップ期は回避手がそもそも少ないので、被リーサル判定は自然に素通りになる。
- **高価な部分（探索検証・回復や温存などの資源を使う回避行動）はフェーズでゲートする。** つまり「サブゴール達成後に毎ターン行う」は**実効的に効き始める時期の記述として正しい**。実装は「常時判定 + フェーズで反応を変える」に寄せる（切替バグを判定1個に局所化できる）。
- エージェントの仕様.md の「前半=コンセプト実現(相手無視)/後半=詰め(相手考慮)」がフェーズの原型。サブゴール判定がその切替スイッチ。

## 実装形（実装済み 2026-07-06: `agents/_base/`）

- **`agents/_base/policy_base.py`**: `BasePolicy`(ABC)。ターン手順・判定の汎用形・マスク・安全ラッパーを固定。
  デッキ必須フック = `judge_subgoal` / `score_setup` / `score_combat`（abstractmethod）+
  必須クラス属性 `GO_FIRST` / `TAKE_MULLIGAN` / `ATTACKER_IDS` / `ENERGY_IDS` / `LINE_PROTECT_IDS`
  （未定義はロード時に TypeError）。任意フック: `plan_attacks` / `attack_damage` / `apply_overrides` / `mask_extra`
- **`agents/_base/meta_tables.py`**: アーキタイプ検出・相手最大打点・ボス採用枚数などのデータ層（エピソード分析で更新）
- 各エージェントdirへは `scripts/sync_base.py` でコピー同期（`--check` で照合、build_submission がハッシュ検査）
- フェーズは一方向遷移にしない（ブリジュラスが全滅したらセットアップ期に戻る）: フェーズ = 判定の現在値、状態を持たない
- 検証: `scripts/check_agent.py`（不変条件）/ `scripts/ab_battle.py`（席入替A/B・`--shadow` 挙動一致率）
