# 提出戦略（アンカー & スカウト運用）

作成: 2026-07-07。採点メカニクス（公式 discussion 714189）からの逆算。

## 採点構造からの帰結

1. **最終スコア ≈ 最終2体の真の強さ × 締切時点で凍結されたプール**。締切後約2週間の収束期間が
   あり「序盤の不運は固定されない」— 締切前のレート貯金は最終評価ではほぼ無意味。
   → **期間中の提出はすべて「実ラダー実験」（P-03の実行手段）。本番は最終2体の選定のみ。**
2. **スコア = アクティブ2体の max** → 同型複製より**負け筋が重ならない補完ペア**が期待値で優位
   （メタスナップショットNotebookの実測: 補完ペア mean_best 82.8% > 最強2複製）。
3. 新規提出はレート600から登り直し（引き継ぎなし）。新しい提出は優先マッチングでσが大きい間は速く動く。
4. ERROR 提出はアクティブ枠を消費しない（回数は消費）。

## 運用: アンカー & スカウト

- **アンカー枠**: 実証済み最良機。動かさない（現在: archaludon v1、890）。
- **スカウト枠**: 実験専用。新デッキ・新ルールの実力測定（現在: marnie v1.1）。
- 回転速度の制約は提出回数（5/日）ではなく泳がせ時間。

## 泳がせ時間（約24戦/日 前提。マリィの推移で較正予定）

| 経過 | 試合数 | 判断 |
|---|---|---|
| 〜1日 | 〜24 | 粗い階級判定のみ。明白な失敗作の即切り可 |
| **2〜3日** | 〜50-70 | **入替判断の標準点**（±50 Elo 級の差が見える） |
| 1週間 | 150+ | 細かい優劣。終盤候補のみ |

- 収束の実用判定: 直近24時間の変動 ±30 以内。

## 流動性による モード切替（測ってから決める）

- 計測: 日次エピソード分析でアーキタイプシェアの日次変化量（L1距離）。
- **高流動**（Archaludon 40.7%→4.9%/4日 の現状）: メタを追わない。カウンター投入は標的が消える。
  汎用に強い機をアンカー固定、スカウトは新戦力測定に使う。
- **低流動**（収束後）: 泳がせ短縮（2日サイクル）で支配デッキへのカウンターを回す。

## 終盤プラン（締切 8/16）

- 最終ペア = **予測される最終プール**（終盤1週間の上位帯 + その一段裏読み）への補完ペア。
- 選定の機械化: ab_battle 総当たりマトリクス × 予測シェア → **E[max(A,B)] 最大化**。
- **最終ペアのロックは 8/12 頃**（無検証ペアの盲目投入は R-25 型事故のリスク。粗い較正時間を残す）。
