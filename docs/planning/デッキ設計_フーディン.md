## 可変打点モデル（このデッキの核。参照実装 `estimate_hand_increase()`）

打点 = 手札×20 なので「このターン手札を何枚増やせるか」の min/max を毎手番計算する:
Abra進化+1 / Kadabra進化+2 / Dunsparce進化+1 / Dudunsparce特性+3 / Fez特性+3（手札から出すなら+2）/
サポートは択一 max(Hilda+1, Dawn+2, Boss−1) / Enriching付与+3（超付きAlakazam前提）。

**リーサル判定との接続（実装上の要点）**: `judge_lethal` に渡す AttackPlan の damage は
**現在手札での確定打点**（(手札−ハンマー消費)×20）を使う。投影打点(max)を使うと
LETHAL_BAND 昇格が「手札を増やす前の早撃ち」を誘発する。増枝はスコア側（ドロー系が
攻撃より高スコア）が担い、確定した時点でプロトコルが発火する。

## ターゲット選択（3段優先 = R-07 の実装形）+ ハンマー会計

1. 残りサイドを取り切れるKO（アクティブ優先、次いで残HP最大）
2. KO可能な中でサイド最多（同数なら残HP最大）
3. 倒せないならアクティブ削り
- 対象に Mist/Rock Fighting Energy: 手持ち Enhanced Hammer 枚数と比較、足りるなら
  「ハンマー使用後の手札減少込み実効打点」で再評価、足りなければ対象変更
- 相手アクティブ残HP≤30 は Kadabra の Super Psy Bolt(30) で節約フィニッシュ

## 資源規律

- **R-11 実データ**: `safe_draws = 山札 − サイド − 1`。カード毎閾値: Poffin<2禁止 /
  Pad<1 / Dawn<3 / Hilda<2 / Telepath付与<2 / Enriching付与<4 / Alakazam進化<3 /
  Dudunsparce特性<3。勝ち切りターンは解除

  need_fez_draw（打点が足りない）or need_fez_for_setup（ボス/進化パーツ/エネ欠け）でのみ着地

- テックのゲート: Psyduck↔相手Duskull / Shaymin↔水系脅威 / Battle Cage↔ドラパルトライン /
  Genesect+Lucky Helmet↔相手ACE SPEC未使用
