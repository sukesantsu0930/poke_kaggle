## 交戦期の運用（E-x）

- **E-1 壁ローテ**: 相手が ex 主体 → Crustle を前（技ダメージ無効）。非 ex（フーディン等）→
  Kanga 前で Run Errand を回す。前の壁が大破（ジャンボ圏外）なら Switch で交代。
- **E-2 回復会計**: ジャンボはダメージ80以上で使用（C-6）。ヒーローマント込みの実効 HP:
  Crustle 170+100=270 / Kanga 300+100=400。
- **E-3 手札破壊**: ゼロシキは C-8 の単調カーブ。ハンドトリマーは「相手手札>=7 かつ自分<=5」
  のみ（自傷なし・ゼロシキ後の重ね撃ちはしない）。
- **E-4 打点**: Scissors 120 は効果無視（ミラーでも通る）。Rapid-Fire は保証値200で評価
  （コインは上振れ扱い、ガルーラ実装と同じ）。弱点はアタッカー毎（Crustle={G}: 対 {G}弱点×2）。
- **E-5 ミラー注意**: 自軍 Kanga の技は相手 Crustle に0点（IMMUNE_TO_EX_ACTIVE は基盤
  guard_damage 済み）。ミラーの主砲は非 ex の Crustle。
