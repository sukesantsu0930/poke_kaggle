## デッキリスト（lolzpo 版・60枚）

- **タマンチュラ (400)×4 → ワナイダー (401)×4** — 主砲。ロケットラッシュ {G}C =
  **自分の場のロケット団の数×30**（全ポケモンがロケット団なので実質 盤面数×30、満面6体=180）。
  非ex（サイド1）・HP130。**特性チャージアップ = 番に1回、トラッシュの基本エネを自分につける**
  （毎ターン無料加速。エネ回収でロケットラッシュが実質使い放題）。にげ2・弱点炎。
- **ミュウツーex (431)×2** — フィニッシャー。HP280（マント込み380）。イレイザーボール {P}{P}C 160
  + のぞむならベンチのエネを2枚までトラッシュして×60追加（最大280）。
  **特性パワーセーバー = 場のロケット団が4匹未満だと技が使えない**。にげ3・弱点悪。
- **フリーザー (414)×2** — 盾。特性レジストヴェール = **自分の場のたねロケット団全員が
  相手のワザの効果を受けない**（ダメージは通る。Damage is not an effect の逆側）。
  ダークフロスト {W}CC 60+ロケット団エネ付きなら+60=120。水1採用はこのため。にげ1・弱点雷。
- **ミミッキュ (434)×3** — ユーティリティ。ほうせきごっこ {P}C = 相手バトル場のテラスタルの技を
  コピー。HP60・**にげ0**（無料ピボット枠）。弱点悪。
- エネ: 基本草(1)×8 / 基本水(3)×1 / **ロケット団エネルギー(15)×4**（ロケット団専用。
  **{P}{D} 2個ぶん** → ミュウツーはこれ1枚+任意1枚で技が起動。エンジンのコスト勘定でも2個扱い）。
- グッズ: むしとりセット(1094)×3（山上7枚から草ポケ+草エネ2枚）/ ハイパーボール(1121)×1
  （手札2捨て・ex含む何でもサーチ = **ミュウツーの唯一のサーチ手段**。ポケパッドはルール持ち不可）/
  **ロケット団のレシーバー(1134)×4**（ロケット団サポートをサーチ）/ ポケパッド(1152)×4 /
  ヒーローマント(1159 ACE SPEC)×1（+100HP）/ ブレイブバングル(1175)×1（非ルール持ちの対exバトル場+30
  → ワナイダー 180+30=210）。
- サポート: **アテナ(1216)×4**（手札5枚まで引く。**場が全員ロケット団なら8枚** = このデッキでは常時8）/
  アポロ(1217)×1（自分のロケット団が前の相手番にきぜつした時のみ。両者手札を山に戻し自分5・相手3 =
  返しの手札破壊）/ **サカキ(1218)×3**（自分のバトル場⇔ベンチ入替 + **相手ベンチ1匹を吊り出し**。
  ボスの指令0枚の代替。無料ピボット兼グスト）/ **ランス(1220)×4**（**先攻1ターン目でも使える**。
  たねロケット団を3枚までサーチ = 展開の心臓）/ リーリエの決心(1227)×3（手札を戻して6ドロー）。
- スタジアム: **ファクトリー(1257)×3** — この番にロケット団サポートを使ったプレイヤーは
  番ごとに1回2ドロー（サポート12枚が全部ロケット団名なのでほぼ毎ターン発動）。

コンセプト: ランス+アテナで盤面をロケット団で埋め（サイド1の主砲ワナイダーが盤面数×30 =
150〜180を2エネで連打）、チャージアップの無料加速で息切れせず、大物はミュウツー160〜280で締める。
フリーザーが技効果（マヒ・ロック等）からたねを守り、サカキが仕上げの吊り出しを担う。
**相手は ex/メガ主体（サイド2〜3）、こちらは主砲が非ex（サイド1）のプライズレース有利**が勝ち筋。

## サブゴール判定（S-0）

```
色を考慮した実効エネ勘定（ロケット団エネ=2個ぶん）で「撃てるアタッカー」が場に1体以上:
  - ワナイダー: 草1含む2個ぶん（ロケットラッシュ）
  - ミュウツー: ロケット団エネ1含む3個ぶん かつ 場のロケット団4匹以上（パワーセーバー）
  - フリーザー: 水1含む3個ぶん（ダークフロスト）
```

枚数ベースの基盤 `payable_attacks` はロケット団エネの2個ぶん勘定を数えられないため、
plan_attacks / 判定は色対応の `_payable()` に差し替える（実装参照）。

## div 記録 — Gate A 監査クイックウィン（2026-07-17）

出典 = Gate A 初回監査（EXP-026。build/rule_audit/2026-07-17/rocket.jsonl 339行、
クラスタ分析 research/eval/rule_audit/2026-07-17_gap_analysis.json）。狙いは負帯の解錠 =
BC 学習の被覆率回復（before 0.848）。採用基準は【L2 非劣化（−2pt以内）∧ check_agent 合格】。
トグルは main.py 冒頭の env 変数（`ROC_RK1A` 等、既定 ON）。A/B は「全トグルON vs 全OFF」の
一括ペア（同日・80戦/枠・**ミラー除外** = EXP-021 教訓①）。

- **div-RK1a【ハード解除・採用（暫定）】タマンチュラ先行チャージ units<1 → units<2**（G1 主成分84行）:
  ロケットラッシュ {G}C=2個ぶんとの整合（R-10「技の実コストから導出」の本義）。序盤はトラッシュが
  空でチャージアップ不能 → 進化ターン即攻撃の唯一の手段。units は eff_units（ロケットエネ2個ぶん）
  経路。スコアは現行 8100 のまま。
- **div-RK3【ソフト・採用（暫定）】レシーバー在庫勘定 have>=1 → have>=2 でブロック**（G3・37行）:
  在庫1枚=今番使えば枯れる、は 12000 帯で使用可（翌番の弾込め+ファクトリー連続発動）。
  「今番プレイ予定のサポートまで在庫に数える」勘定ミスの修正。R-11 ガード（safe_draws>=1）維持。
- **div-RK5a【ソフト・採用（暫定）】チャージアップ units>=2 打ち止め撤廃**（G5・20行、lolzpo 純度100%）:

- **div-RK6【ソフト・採用（暫定）】ポケパッド combat 禁止 rockets>=4 → rockets>=6**（G6・24行）:
  盤面数=打点（ロケットラッシュ×30）なので5〜6匹目にも価値。rockets 4-5 のスコアは 6500 の低帯

  LETHAL_BAND へ昇格。ATTACK 昇格と RETREAT ブロックは基盤の共通処理がそのまま効く。
  (5) 吊り先選択（SWITCH, 相手側）: KO可能な個体に 20000+サイド×1000−HP の優先
