# CODEX への依頼内容
## デッキの評価関数，プロトコル
イメージ：一人回しで，デッキのコンセプトをどれだけ実現できるか．
相手からまったく干渉を受けないという前提で，デッキに紐づいた動きが実現できる確率を平均して出す．
例）ドラパルトのファントムダイブを打つ，がコンセプトのでっきなら，ドラパルトのファントムダイブを打つまでのターンを評価する．
基本的に，デッキのコンセプトは打ちたい技で決定するとする．
ただ，評価関数，プロトコルがどんな仕様がいいかは考えたい．一々デッキごとにコードを打つのがいいのか，しかし，一人回しの環境は作るべき．

ただ，デッキを評価するためにはエージェント（が複数）も必要で，何とも言えない．すぐに実装すべきものでもないかもしれない．トークンに余裕があるときかな．
