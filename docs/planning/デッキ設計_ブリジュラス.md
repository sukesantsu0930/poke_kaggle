# デッキ設計: ブリジュラス（Archaludon ex + Cinderace）

作成: 2026-07-06。参照実装: `research/external/kaggle_notebooks/a-sample-archaludon-75-wr-vs-my-1300-starmie/`（1300+ Starmie 作者が公開、対 1300+ Starmie 1000戦 74.4% — ただし相手が鋼弱点の Froslass 混成なので過大評価注意、と作者注記）。用語は `用語とターン手順.md` に従う。

## デッキリスト（CityLeague 準優勝リスト由来、参照実装同梱）

- ジュラルドン Duraludon (169) ×4 — たね・鋼・HP130。Hammer In {M}=30 / **Raging Hammer {M}{M}{C} = 80 + ダメカン×10**
- **ブリジュラス Archaludon ex (190) ×4** — 1進化・HP300。**特性 Assemble Alloy**: 手札から進化時、トラッシュから鋼エネを2枚まで自軍鋼ポケモンに付与。**Metal Defender {M}{M}{M} = 220**（次の相手番、弱点なし）
- エースバーン Cinderace (666) ×4 — 2進化・HP160。**特性 Explosiveness**: セットアップ時に手札から裏向きでアクティブに置ける（＝たね扱いで開始）。**Turbo Flare {C} = 50 + 山から基本エネ3枚までベンチに付与**
- ジーランス Relicanth (57) ×1 — Memory Dive: 進化ポケモンが進化前の技を使える（ブリジュラス→Raging Hammer 解禁）
- グッズ: Poke Pad ×4, Ultra Ball ×4, Pokegear ×4, Night Stretcher ×3, Jumbo Ice Cream(回復80) ×4, Hero's Cape(+100HP) ×1
- サポート: **ボスの指令 ×4**, Explorer's Guidance ×4, Lillie ×4
- スタジアム: Full Metal Lab(鋼への攻撃-30) ×4
- 鋼エネ (8) ×11

注意: Cinderace は進化元(Scorbunny/Raboot)不採用。**Explosiveness（初手セットアップ）でしか出せない** → 初手依存。×4はそのため。

## サブゴール判定（案）

```
場（アクティブ+ベンチ）に Archaludon ex(190) が存在
AND その個体が Metal Defender のコスト {M}{M}{M} を払える（エネ3枚以上）
```

- 初版はこれで開始。改善候補: 「アクティブに出られる」（にげるコスト充足 or 既にアクティブ）を AND に足すか、2体目の育成状況を段階サブゴール化するか。
- 実装は ptcg-abc BasePolicy の `can_attack(p)`（技コストからの導出）をそのまま使える形。

## セットアップ期の優先則（サブゴール達成前）

参照実装のスコア構造から抽出。経路が2本ある:

**経路A（Cinderace 始動、理想）**
1. SETUP_ACTIVE: Cinderace 最優先（参照実装スコア 100000）> Duraludon (20000) > Relicanth (5000)
2. ベンチに Duraludon を置く（**2体目まで**。1体目を狩られた時の保険 — 被リーサル判定との接続点）
3. T1 Turbo Flare: 山から鋼エネ3枚 → **ベンチの Duraludon に集約**
4. Duraludon → Archaludon ex 進化。**トラッシュに鋼エネがある時を優先**（Assemble Alloy の回収を空振りさせない。Ultra Ball のコストで鋼エネを先に落とす、の順序連動）
5. 手張りはブリジュラスライン優先

**経路B（Cinderace 不発）**
- Duraludon をアクティブに、手張り+Assemble Alloy 頼みで加速。Raging Hammer（{M}{M}{C}=80+ダメカン×10）を中継打点にする
- 経路Bでは Ultra Ball 等での**鋼エネのトラッシュ送りの価値が上がる**（Assemble Alloy の弾作り）

## 交戦期（サブゴール達成後）

- ターン手順（リーサル→負け筋カット→交戦優先則）を毎手適用
- デフォルト攻撃 Metal Defender 220。Raging Hammer への切替は「80+ダメカン×10 ≥ 相手残HP < 220 が偽」つまり Raging Hammer でしか届かない/220で過剰な時（Relicanth 在場が条件）
- 参照実装から流し込む交戦部品: ボス多段ロジック（リーサル→温存→ベンチKO→ボススタール）、Jumbo Ice Cream 回復判定（Raging Hammer 圏を自分で消さない条件付き）、`apply_overrides()` のマッチアップ上書き、相手前ターン技追跡（Mega Brave 硬直の利用）

## 負け筋カット（R-08）の入力

- 相手最大打点テーブル: 参照実装の値（crustle 120 / hop 220 / lucario 270 / starmie 210 / generic 220）は**6月メタ**。現メタ（Marnie/Munkidori 急伸・Alakazam 最大シェア・Starmie 復調）向けに**エピソード分析から再作成が必要** → タスク化
- ボス想定: 相手のボス採用枚数はアーキタイプ既知値を使い、相手トラッシュの使用済み枚数で解除判定（R-08 準拠）
- 自軍の急所: ベンチの育成中 Duraludon（HP130）と Cinderace（HP160）。ボス想定下では「エネ付きジュラルドンを1体に集中させない」がセットアップ期から効く
