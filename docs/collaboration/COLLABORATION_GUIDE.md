# 共同作業ガイド

このリポジトリでは、役割を分けて作業します。

## 役割

### デッキ研究担当

やること:

- はやりのデッキや強そうなアーキタイプを調べる
- 使いたいカードを調べる
- ポケカ公式サイトで60枚デッキを作り、デッキコードを発行する
- `run\02_deck\デッキコード登録.bat` にデッキコードを入れる
- GUIでプレイする
- 解析的に測れる評価指標を考える
- 良いデッキコードと評価メモを助友に送る

やらなくてよいこと:

- Agentを作る
- Agentを使って大量対戦し、平均勝率を取る
- CSVやPythonを直接編集する

### ストラテジー研究担当

やること:

- ルールやカード効果で重要そうなことを発見する
- 「先攻/後攻」「進化」「エネルギー」「ベンチ」「サイド」などの戦略を調べる
- プレイ中に気づいた判断ルールを助友に送る

### 実装・評価担当

主に触る場所:

- `agents/`
- `scripts/`
- `experiments/`
- `proposals/`

やること:

- プロジェクト全体を管理する
- エージェントに判断ルールを入れる
- 学習やモデル開発を行う
- デッキとエージェントの組み合わせを評価する
- Agentを使ったモンテカルロ評価を回す
- 勝率や失敗例をまとめる
- Kaggle提出zipを作る

## 初心者メンバーの作業場所

初心者メンバーは、基本的にファイルを編集しません。

やることは、流行デッキを調べ、公式デッキコードをシステムに入れて、GUIでプレイし、解析的に評価することです。良いデッキができたら、デッキコードと評価メモを助友に直接送ってください。

慣れるまでは以下は編集しないでください。

- `agents/*.py`
- `scripts/*.py`
- `submission/`
- `cg/`
- `models/`
- `Dockerfile`
- `docker-compose.yml`
- `decks/`
- `proposals/`
- `research/`

## デッキコードのルール

初心者メンバーはCSVを直接書きません。

ポケカ公式サイトでデッキを作り、次のようなデッキコードをシステムに入れてください。

```text
4GGxYc-KmW2Iv-8c4c8c
```

```text
run\02_deck\デッキコード登録.bat
```

`OK` と出たものだけGUIで使えます。`NG` が出たら、公式サイト側でデッキを直して、もう一度デッキコードを入れてください。

## メモのルール

初心者メンバーはMarkdownファイルを編集しなくて大丈夫です。

良いデッキができたら、チャットやメモ帳で次を助友に送ってください。

- デッキコード
- デッキの狙い
- 主軸カード
- 使いたい技や勝ち筋
- 何が強そうだったか
- 何が弱そうだったか
- どの場面で困ったか
- 次に試したい変更

## Gitの最低限

作業前は、GitHub Desktopで最新版を取ってください。

初心者メンバーは、基本的にこれだけで大丈夫です。

採用候補はデッキコードと気づいたことを助友に直接送ってください。

## 提案から評価までの流れ

1. 流行デッキや強そうなカードを調べる
2. 解析的に見る評価指標を考える
3. 公式サイトでデッキを作る
4. `run\02_deck\デッキコード登録.bat` にデッキコードを入れる
5. `OK` ならGUIでプレイする
6. 良いデッキコードと評価メモを助友に送る
7. 実装担当が `decks/`, `agents/`, `proposals/` や評価に反映する
