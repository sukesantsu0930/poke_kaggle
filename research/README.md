# 研究メモ置き場

非エンジニアメンバー向けの研究メモ置き場です。

## フォルダ

- `deck_notes/`: デッキ案、採用理由、事故要因
- `card_notes/`: 個別カードのメモ
- `strategy_notes/`: プレイ方針、エージェントに入れたい判断ルール
- `rule_findings/`: ルールや仕様の発見
- `external/`: 外部公開資産の取り込み場所（実装担当向け。ptcg-abc、公開Notebook。中身はGit管理外、詳細は `external/README.md`）

## ルール

1ファイル1テーマで書いてください。

よい例:

- `deck_notes/deck_002_fast_attack.md`
- `strategy_notes/bench_setup_priority.md`
- `rule_findings/first_turn_limitations.md`

避けたい例:

- `memo.md`
- `latest.md`
- `strong_deck.md`
