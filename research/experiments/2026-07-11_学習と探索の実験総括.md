# 学習と探索の実験総括（2026-07-09 〜 07-11）

対象: EXP-001〜011（生データは [LEDGER.md](LEDGER.md)、時系列は [PROJECT_DIARY](../../docs/planning/PROJECT_DIARY.md)）。
3日間で「学習でエージェントを強くする」路線を体系的に検証した。結論を先に:

> **手書きルールは強い局所最適であり、予算内の学習・探索はいずれもそれを上回れなかった。
> ただし margin（上位人間との差）自体は大きいまま存在する。生き残った学習は
> 「ラベルが最初から打たれている教師あり」だけで、その役割は方策の代替ではなく
> 計測器（どこを直すか）と判断材料（V・脅威確率）の供給である。**

検証は5層の漏斗（L0 オフライン / L1 不変条件 / L2 プール / L3 人間アンカー / L4 ラダー、
正典: [評価方法.md](../../docs/planning/評価方法.md)）に従い、採用基準は事前登録
（L2 で +7pt@320試合 ∧ holdout 非劣化）。**全実験がこの基準で判定され、例外はない。**

---

## 問い1: ルール強度 θ は学習できるか → **No（現行の φ の粒度では構造的に不可能）**

| 実験 | 構成 | 結果 |
|---|---|---|
| EXP-002 | 模倣θ（条件付きロジット、上位ピロット24,645決定） | held-out 一致率は改善（62.6→63.1%）、**L2 は −18pt**。reject |
| EXP-006 | CEM（勝率の直接最適化、サーバー30反復・69,120試合） | screening **−24.3pt**。reject |

敗因は3つ、いずれも実測で特定:

1. **winner's curse**: CEM の出力は360評価の argmax サンプル。ノイズ最大値の理論上振れ
   +13.4pt と観測 +13.7pt が一致。「探索中に見えた高スコア」は θ の強さではなかった
2. **選抜の SNR ≈ 0**: μ の30反復軌跡は完全に横ばい（傾き t=−0.66）。評価ノイズ（±4.8pt）が
   候補間の真の差を埋没させ、エリート選抜は実力でなく運を選んでいた
3. **探索地形が平坦か崖**: 摂動実験（518決定）で σ=2000 でも決定の3.5%しか変わらない。
   θ は reason 単位の**状態非依存の一律シフト**しかできず、軌跡の局所的変更が表現できない。
   実際に選ばれた決定の64%は top-k 24 reason の対象外だった

**含意**: 「θ 最適化 → 残差が新述語を指す」という当初テーゼは順序が逆。φ を十分細分化して
初めて θ 空間に勾配が生まれる。θ 系は φ 細分化まで棚上げ。

## 問い2: 探索（決定時の先読み）は勝率を上げるか → **No（現構成では。骨格の可能性は残るが予算内で検証不能）**

前提の技術検証（EXP-007 スパイク）は全項目グリーン: エンジン公式の search API は実対戦の
obs から動き、決定化 rollout は 30〜40ms/本、実対戦への副作用ゼロ、600秒プールにも収まる。
実装（EXP-008）も健全: search OFF で shadow 一致100%、全7機の不変条件通過、提出 zip 同梱可。

しかし勝率は動かなかった:

| 構成（marnie、同一凍結プール） | L2 プール320試合 | holdout 90試合 |
|---|---|---|
| 探索なし（ルールのみ） | **62.4%** | 93.1% |
| 探索 + V v1 葉（EXP-009） | 59.6%（−2.8pt） | 87.9% |
| 探索 + V v3 葉（EXP-011） | 57.5%（−4.9pt） | 95.8% |
| 探索 + rollout 葉（EXP-011） | 60.3%（−2.1pt） | 87.0% |

**EXP-010 の教訓**: rollout 葉は screening 80試合で 70.7%（+8.3pt）を出して昇格したが、
確定320試合で 60.3% に反落。80+320 の統合推定 ≈ 62.4% = ルールと同値。
**screening→confirm の2段構えが winner's curse を正しく検死した**（この規律がなければ
「+8.3pt の改善」を信じて L4 に出していた）。

敗因は3つ:

1. **サンプル飢餓**: 1決定1秒 = 候補あたり rollout 5〜6本（±20pt）。僅差の候補の真の差
   （数pt）を解像できず、選択は実質コイン投げ → ルールの良い事前分布をノイズで上書き
2. **評価器の歪み**: rollout 内の相手役（GenericPolicy）は本番の相手（tuned）より弱く、
   プレイアウトが楽観に歪む。V 葉はモデル誤差を max が系統的に拾う（optimizer's curse）
3. **トリガーの逆説**: 探索は「ルールが迷う場面」（margin<8000）でのみ発火する設計だが、
   迷う場面 = 候補がほぼ等価 = 賭け金が小さい。ゲームを落とす「確信を持った誤り」は
   margin が大きく、探索は一度も触れていない

**AlphaZero が成立しない理由（定量）**: AZ の改善オペレータ `search(π,V) > π` は、
(a) 完全情報・無運（1シミュレーションの情報量が桁違い）、(b) 800 sims/手、
(c) 数百万試合の自己対戦、を前提とする。ここでは (a) 運と隠れ情報が1本の rollout の
情報を希釈し、(b) 相当をやると24秒/手 = 24分/試合、(c) は必要量から3〜4桁不足。
実測でも `search(π) ≈ π`（60.3 vs 62.4）でオペレータは恒等写像だった。
なお不完全情報カードゲームは研究史的にも AZ の主戦場ではない（ポーカーは CFR 系が解いた）。

## 問い3: 盤面価値 V(s) は学習できるか → **Yes（予測器として。ただし葉評価としては未だ勝率に変換されない）**

教師 = 公開エピソード（対戦生成ゼロ）。222k局面 / 760対局 / 3.5日分。

| バージョン | 特徴量 | holdout AUC | 知見 |
|---|---|---|---|
| baseline | サイド差のみ | 0.694 | 合格下限 |
| v1 | 盤面47次元 | 0.727 | ターン帯単調 0.62→0.76→0.84（正しい V の形） |
| v2 | + 自手札の中身11 | 0.723 | **無風（本物の null）**。手札は短期脅威に効くが最終勝敗は盤面が語る |
| v3 | + 両者アーキタイプ one-hot | **0.757** | **+3.4pt。「良い盤面」の定義はマッチアップ依存** |
| 脅威分類器 | v3 と同特徴 | **0.825** | 「2ターン以内のサイド損失」は盤面から強く予測できる |

- **学習曲線は未飽和**: 250/500/760対局 = 0.701/0.713/0.723。データは毎日+250対局（無料）
- **アーキタイプ別 AUC はデータ量に比例**: marnie 12k行 0.80 / kangaskhan 1.7k行 0.62
  → 「デッキ毎の専用 V」は分割でなく**条件付け**で実現し、データ蓄積で少数派が底上げされる
- 設計規約が効いた: 特徴量の正本1ファイル（train/serve 共通）、エピソード単位の分割
  （行単位はリーク）、FEATURE_VERSION 不一致の自動縮退

## 横断的な教訓（戦略レポートの骨子候補）

1. **1試合1ビット問題はスケールを変えて3回現れた**: CEM の候補選抜 / rollout の候補選抜 /
   screening→confirm。いずれも「ノイズ > 信号のまま argmax を取ると、運を拾う」
2. **L0 と L2 は乖離する**: held-out 一致率改善→勝率−18pt（EXP-002）、AUC+3.4pt→勝率−5pt
   （EXP-011）。オフライン指標の改善は勝率の改善を含意しない。**判定は必ず対戦で**
3. **事前登録と2段測定が誤採用を2回防いだ**（EXP-002 を模倣θのデプロイから、EXP-010 を
   L4 提出から）
4. **ゲームの構造**: ポケカは確率的だが「方策への感度が疎」——技量は少数の分水嶺の決定に
   濃縮され、僅差の判断は勝率をほぼ動かさない。混合戦略は静的な相手には不要（決定論で十分）
5. **margin の在り処**: 上位人間との一致率は 63〜65%（3手に1手は違う）で改善余地は大きい。
   それは「ルールが迷う場所」ではなく「ルールが確信して間違う場所」にあり、
   検出器は divergence mining（実績: marnie 一致率37→85%、対フーディン+7.5pt）
