# 実行用ファイル

自分でダブルクリックして使うファイルは、このフォルダに集約しています。

## よく使うもの

- `カード画像生成.bat`: 初回だけ実行。ローカルカード画像を作ります。
- `デッキコード登録.bat`: 公式サイトのデッキコードを、このプロジェクトで使えるCSVに変換します。
- `デッキ可視化.bat`: deck CSV の全体像を画像つきHTMLで確認します。
- `GUI起動.bat`: 手動プレイGUIを起動します。

## 必要になったら使うもの

- `リプレイJSON作成.bat`: 公式Visualizer用のローカル対戦JSONを作ります。
- `公式Visualizerフォルダを開く.bat`: 手元の公式Visualizer notebookフォルダを開きます。
- `1000エピソード分析.bat`: 1000試合のエピソード分析を走らせます。
- `1000_episode_analysis.bat`: 上と同じ内容の英語ファイル名版です。

このフォルダの `.bat` は、どこから起動してもプロジェクト直下を基準に動くようにしています。
