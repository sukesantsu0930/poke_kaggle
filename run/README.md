# 実行用ファイルの使い方

自分でダブルクリックして使うファイルは、このフォルダに集めています。

基本は次の順番です。

1. 初回だけ `カード画像生成.bat`
2. デッキコードを使うなら `デッキコード登録.bat`
3. デッキ内容を確認するなら `デッキ可視化.bat`
4. 自分で対戦して試すなら `GUI起動.bat`
5. エージェント同士の動きを見るなら `リプレイJSON作成.bat`

黒い画面が出たら、完了するまで閉じないでください。`DONE` や `OK` が出れば成功です。`FAILED`、`NG`、`ERROR` が出た場合は、その画面を助友に送ってください。

## カード画像生成.bat

初回だけ使います。

カード画像をローカルに作ります。これを実行しておくと、GUI やデッキ可視化でカード画像が表示されます。

使い方:

1. `カード画像生成.bat` をダブルクリックする
2. 黒い画面が開く
3. `DONE` と出るまで待つ
4. 何かキーを押して閉じる

途中で閉じると画像生成が途中で止まります。

## デッキコード登録.bat

公式サイトのデッキコードを、このシステムで使えるデッキファイルに変換します。

使い方:

1. ポケカ公式サイトでデッキを作る
2. デッキコードをコピーする
3. `デッキコード登録.bat` をダブルクリックする
4. `Deck code:` の右にデッキコードを貼り付ける
5. Enter を押す

成功すると `OK decks\local\deck_....csv` のように表示されます。このデッキは GUI で選べるようになります。

失敗すると `NG` または `ERROR` が出ます。その場合は、公式サイト側でデッキを直してからもう一度実行してください。

## デッキ可視化.bat

デッキ全体を画像つきのページで確認します。

使い方:

1. `デッキ可視化.bat` をダブルクリックする
2. `Deck CSV:` と表示される
3. 見たいデッキファイルの場所を入力する
4. Enter を押す

何も入力せず Enter を押すと、既定のクマシュン・オーガポン候補デッキを表示します。

出力された HTML は `experiments\deck_views\` に保存されます。通常は自動でブラウザが開きます。

入力例:

```text
decks\local\deck_4GGxYc_KmW2Iv_8c4c8c.csv
```

## GUI起動.bat

自分で両方のプレイヤーを操作して、デッキを試すための画面を開きます。

使い方:

1. `GUI起動.bat` をダブルクリックする
2. ブラウザが開く
3. 左側で Player 0 と Player 1 のデッキを選ぶ
4. 対戦を開始する
5. 画面に出る選択肢を選んで進める

黒い画面はサーバーです。GUI を使っている間は閉じないでください。

ブラウザが自動で開かない場合は、次のURLを手で開いてください。

```text
http://127.0.0.1:8765
```

終了するときは、黒い画面を閉じてください。

## リプレイJSON作成.bat

エージェント同士で1試合を実行し、公式 Visualizer で見るための JSON を作ります。

最低限、次の4つを指定します。

- `Agent 0`
- `Deck 0`
- `Agent 1`
- `Deck 1`

使い方:

1. `リプレイJSON作成.bat` をダブルクリックする
2. `Agent 0` にエージェントの場所を入力する
3. `Deck 0` に Player 0 のデッキファイルを入力する
4. `Agent 1` に相手エージェントの場所を入力する
5. `Deck 1` に Player 1 のデッキファイルを入力する
6. 実行が終わるまで待つ

何も入力せず Enter を押すと、既定のクマシュン・オーガポン用エージェントとデッキで実行します。

入力例:

```text
Agent 0: agents\cubchoo_ogerpon_rb
Deck 0 : decks\candidates\2026-06-30_top5\winrate_1_cubchoo_ogerpon.csv
Agent 1: agents\cubchoo_ogerpon_rb
Deck 1 : decks\candidates\2026-06-30_top5\winrate_1_cubchoo_ogerpon.csv
```

出力先:

```text
experiments\visualizer\latest_replay.json
experiments\visualizer\latest_agent_log.json
```

`latest_replay.json` は公式 Visualizer で見るためのファイルです。

`latest_agent_log.json` は、各ターンで `agent0` と `agent1` がどの選択肢から何を選んだかを見るための確認用ファイルです。

## 公式Visualizerフォルダを開く.bat

エージェントとデッキを選び、リプレイ JSON を作り、そのまま公式 Visualizer を開くための画面を起動します。

使い方:

1. `公式Visualizerフォルダを開く.bat` をダブルクリックする
2. ブラウザで `Agent 0`、`Deck 0`、`Agent 1`、`Deck 1` を選ぶ
3. `Generate Replay JSON` を押す
4. `DONE` と表示されたら `Open Official Visualizer` を押す
5. 公式 Visualizer が別タブで開く

このプロジェクトの手動GUIとは別物です。公式 Visualizer は、作成済みのリプレイを見るために使います。

黒い画面はローカルサーバーです。使っている間は閉じないでください。

## 1000エピソード分析.bat

Kaggle の上位エピソードをまとめて分析するときに使います。

通常のデッキ作成や手動プレイでは使いません。

使い方:

1. `1000エピソード分析.bat` をダブルクリックする
2. 終わるまで待つ

出力は実行日ごとに `research\episode_deck_analysis\runs\` 以下へ保存されます。時間がかかることがあります。

## 1000_episode_analysis.bat

`1000エピソード分析.bat` と同じ内容です。

日本語ファイル名でうまく動かない環境があれば、こちらを使います。
